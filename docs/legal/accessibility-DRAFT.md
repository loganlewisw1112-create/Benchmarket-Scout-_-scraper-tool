We want Benchmark Scout to be usable by everyone, and we aim to meet the Web
Content Accessibility Guidelines (WCAG) 2.2 at level AA.

## What we've checked

- Automated checks (axe-core and Lighthouse) on the home page, the privacy
  page, and shared report pages. The last Lighthouse accessibility scores were
  0.96. The one recurring failure, low text contrast, was fixed in v0.5.0.
- Keyboard-only navigation through the report form and report pages.
- Layouts at phone, tablet, and desktop widths.

## Known limitations

- The downloadable PDF report is generated in the browser and is not yet a
  tagged, screen-reader-structured PDF. The same information is available as
  accessible HTML on the report page.
- Automated tools can't catch everything. We have not yet run a full
  assistive-technology review with a screen reader.
- The site uses a light color scheme only.
